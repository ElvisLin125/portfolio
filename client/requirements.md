## Packages
framer-motion | Core requirement for cinematic, slow-reveal A24-style animations
react-hook-form | Form state management for the contact section
@hookform/resolvers | Zod validation integration for the contact form

## Notes
The application features a strict, dark "brutalist cinematic" aesthetic (A24 inspired).
The film-grain overlay is applied via CSS.
Data is fetched via TanStack Query from the endpoints defined in shared/routes.ts.
